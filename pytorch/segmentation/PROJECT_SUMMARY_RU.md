# Резюме проекта: U-Net Сегментация для нейронного анализа изображений

## Обзор
Это комплексный проект семантической сегментации с использованием архитектур U-Net для анализа биомедицинских изображений, специально разработанный для сегментации нейронных структур на 6 различных классов:
1. Митохондрии
2. Постсинаптические плотности (PSD)
3. Везикулы
4. Аксон
5. Границы
6. Границы митохондрий

## Структура проекта

### Основные компоненты:
- **src/**: Содержит все исходные кодовые модули
- **test_data/**: Содержит тестовые изображения, эталонные маски и предварительно обученные файлы модели
  - `img_in/`: Входные тестовые изображения
  - `img_etal/`: Эталонные аннотации (по классам)
  - `model_data/`: Предварительно обученные веса модели и конфигурации

### Основные файлы архитектуры:
- **models.py**: Содержит несколько вариантов U-Net:
  - Стандартный U-Net
  - Маленький U-Net (v1 и v3)
  - Мобильный U-Net (с оптимизированными инвертированными остаточными блоками)
  - Lars76 U-Net (на основе ResNet34 с SMP)

- **model_block.py**: Основные строительные блоки (DoubleConv, Down, Up, OutConv)

- **pipeliner.py**: Основной конвейер обучения/предсказания, который управляет обучением модели и инференсом

### Ключевые особенности:

1. **Несколько архитектур U-Net**:
   - Стандартный U-Net с пропускными соединениями
   - Легкий маленький U-Net для более быстрого инференса
   - Мобильный U-Net, оптимизированный для мобильного развертывания
   - Пользовательская архитектура v3 с модифицированными блоками Up

2. **Расширенные возможности обучения**:
   - Несколько функций активации (сигмоида, softsign, арктангенс и др.)
   - Несколько функций потерь (Dice, BCE, MSE, Huber)
   - Поддержка многоклассовой классификации
   - Балансировка классов
   - Разбиение на тайлы для больших изображений

3. **Поддержка тайлинга**:
   - Обработка больших изображений путем разбиения на тайлы
   - Обработка перекрытий для уменьшения краевых артефактов
   - Реконструкция из предсказаний тайлов

4. **Комплексная оценка**:
   - Несколько метрик: Dice, Jaccard, Accuracy, Precision, Recall, F-score
   - Пользовательские кластерные метрики
   - Подробная отчетность в текстовом и CSV форматах

5. **Экспорт модели**:
   - Поддержка экспорта TorchScript (как стандартный .pt, так и мобильный .ptl)
   - Сохранение конвейера с конфигурацией и весами

6. **Пользовательский интерфейс**:
   - Веб-интерфейс Gradio для интерактивной сегментации
   - Блокнот Jupyter для исследования
   - Скрипты командной строки

### Ключевые скрипты:
- **gradio_interface_segmentation.py**: Интерактивный веб-интерфейс Gradio
- **press.py**: Скрипт тестирования с визуализацией
- **pth_converter.py & pth_to_pt.py**: Инструменты конвертации модели для мобильного развертывания
- **InterectiveTest.ipynb**: Блокнот Jupyter для интерактивного тестирования

### Обучающий конвейер:
- Использует PyTorch с интеграцией segmentation_models_pytorch (SMP)
- Пользовательские функции потерь и метрики
- Пакетная обработка и аугментация данных
- Проверка во время обучения
- Функция ранней остановки

### Обработка данных:
- Обрабатывает градационные изображения (одноканальный ввод)
- Многоклассовая сегментация (6 выходных каналов)
- Предварительная обработка и нормализация
- Разбиение на тайлы для больших изображений, которые не помещаются в память

Проект, по-видимому, специально разработан для сегментации нейронных изображений электронной микроскопии, с акцентом на биологические структуры, такие как митохондрии, синапсы (PSD) и везикулы. Модель была обучена на определенном наборе данных и может использоваться для инференса новых изображений через интерфейс Gradio или скрипты Python.
